# OpenEvidence MCP

Third-party local MCP bridge that connects compatible agents to the user's authenticated OpenEvidence browser session through a local relay and browser extension.

- Confirmed source remote: [htlin222/openevidence-mcp](https://github.com/htlin222/openevidence-mcp).
- Setup and operational documentation: [owning README](https://github.com/htlin222/openevidence-mcp/blob/HEAD/README.md).
- The owning README describes Node 20 or newer, `make all` setup, loading its extension, and keeping an authenticated OpenEvidence tab open. Consult that README for current platform prerequisites and supported commands.

This is an unofficial third-party project, not a user-authored tool. Authentication remains in the user's browser. Browser profiles, cookies, credentials, local answer databases, and clinical query/output files are not imported into this repository. A documented setup is not proof that the user's live bridge is currently authenticated or working.

This entry records the existing clone's remote without duplicating third-party source. Source: local Git remote and owning project README, reviewed 2026-11-14. No browser access, query submission, installation, or integration validation was performed during this import.

# ITE Reasoning Deck

Source-linked Anki deck builder with one scheduled card per question, sequential cloze reveal, reasoning diagrams, clinical figures, and source references.

- Authoritative code: [moaziniya-jpg/ite-reasoning-deck](https://github.com/moaziniya-jpg/ite-reasoning-deck).
- Build and verification: use the [owning README](https://github.com/moaziniya-jpg/ite-reasoning-deck/blob/HEAD/README.md) for Python requirements, input layout, `extract_sources.py`, `build_deck.py`, and `verify_deck.py` commands.
- Large study assets and final packages: [existing Drive project folder](https://drive.google.com/drive/folders/1def-kkUxWq9XB_AFFQH_doXxniBWq3Ue).

In Anki, **N** reveals the next blank within the current card; **Show Answer** reveals the rationale before rating recall. Follow the source README's unresolved-answer and review-scope notes. The full deck has not received an independent contemporary medical review.

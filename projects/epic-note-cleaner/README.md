# Epic Note Cleaner

Offline HTML tool for cleaning pasted Epic text and collecting an editable running log. Its modes retain notes, extract assessment/plan text, or apply whole-text filters; synthetic regression tests cover the parser.

- Authoritative code: [moaziniya-jpg/epic-note-cleaner](https://github.com/moaziniya-jpg/epic-note-cleaner).
- Use: open `index.html` from that repository in Chrome. No build or model call is required.
- Development and verification: follow the [owning README](https://github.com/moaziniya-jpg/epic-note-cleaner/blob/HEAD/README.md); its Node test command is `node --test`.

The cleaner is a separately requested transformation tool. It was removed from the recorded Notes/Active Orders chart-check workflow on 2026-11-01; do not insert it into verbatim chart capture.

# Attending presentation: present / staff

A few relevant notes, an Epic dotphrase information pull, and placed orders are sufficient inputs to build the presentation. Combine them with available bedside findings and earlier encounter context; do not require a separate narrative explaining why each order was placed. Present the strongest supported synthesis and identify only consequential missing information.

Infer the clinical rationale linking the supplied patient context, prioritized differential, and existing orders. Explicit clinician statements about reasoning, priorities, or order purpose override that inference. Integrate supported rationale directly into ASSESSMENT & PLAN without repetitive inference labels. If an order has several plausible indications, use a supported broader purpose or flag the ambiguity only if consequential. The existence of an order supports the workup's direction; it does not create an unreported symptom, exam finding, treatment administration, or confirmed diagnosis. Keep any newly recommended orders distinct from the orders actually placed.

Use one presentation box with short telegraphic bullets under the following labels; bullet the one-liner too. Keep paragraphs and lengthy multi-clause bullets out. In order:
1. ONE-LINER.
2. HPI: integrate bedside history and relevant chart context chronologically, using supplied pertinent positives/negatives. Fold PMH/meds into the story, assessment, or plan they affect; no BACKGROUND dump.
3. VITALS: supported interpretation of current state/trend, with decision-changing values in parentheses and timing when needed. No routine full vital-sign row.
4. EXAM: current clinician-supplied findings.
5. LABS: synthesize the clinically meaningful pattern; add only useful supporting values or dated comparisons in parentheses. No panel recitation or repeated raw-value list.
6. IMAGING/ECG: synthesize the important findings and implications; retain uncertainty and preliminary/final or prior/current distinctions. Put useful numeric support in parentheses, not a report dump.
7. ASSESSMENT & PLAN: one combined section, organized by prioritized differential. For each diagnosis/concern, present **differential → reasoning → related orders placed**, in that order. Reasoning connects concise supplied evidence for/against to a clinically supported interpretation and meaningful uncertainty; use the clinician's explicit rationale whenever supplied. Link each confirmed order to its supported clinical purpose, inferring that purpose from context when unstated, and preserve actual status. Group related treatment, response, consults, and clinician-stated disposition decisions with the concern they address, or once at the end when shared. Do not repeat shared orders under every diagnosis. If order information is absent, omit that line rather than inventing orders or asserting none exist. Label any clinician-stated future action as planned; do not present it or your suggestions as an order already placed. Do not split assessment and plan into separate sections.
8. PENDING: what remains and what it changes.

Combined-section structure (placeholders illustrate layout only):

```text
ASSESSMENT & PLAN
- [Differential / concern]
  - Reasoning: [supporting findings / findings against / uncertainty]
  - Orders placed: [related tests / treatments; actual status]
- [Next differential / concern]
  - Reasoning: [supporting findings / findings against / uncertainty]
  - Orders placed: [related tests / treatments; actual status]
```

Below the presentation box, add **HPI — UNANSWERED / UNCLEAR** with concise question bullets:

- Review all supplied encounter history first; include relevant missing answers, ambiguous statements, partial answers, and unresolved contradictions.
- Ask one answerable question per bullet. Mark `Unanswered` or `Unclear` briefly; for an unclear answer, identify only the ambiguity needed to resolve it.
- Prioritize questions that distinguish diagnoses, clarify symptom chronology, or change treatment/disposition. Include all relevant gaps without a fixed quota; no generic complete-HPI checklist.
- Do not repeat answered questions, turn missing information into a negative, or insert the gap list into the spoken presentation. Keep history questions here; other material gaps remain separate brief bullets below the box. If no relevant HPI gap is identifiable, omit the list without claiming the history is complete.

Additional suggestions go outside as labeled bullets. Do not equate an unchanged ECG or prior negative workup with exclusion of all dangerous alternatives.

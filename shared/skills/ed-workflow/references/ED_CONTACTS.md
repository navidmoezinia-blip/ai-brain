## TDCJ Hospital Galveston (HG) disposition (flowchart, as of 2022-03-07)

- **Admission:** call CMC Utilization Review **409-747-8624** (no pre-auth # needed;
  handled internally by TDCJ) → Epic Dispo tab: admit category + bed request order
  with admit service + consult order → HG Bed Placement assigns bed/team (see
  "PPC Comment" column in Epic for contact) → doc-to-doc → then call **CMC Bed
  Control 409-772-0120**.
- **Discharged "home" (TDCJ holdover):** Dispo = Transfer – TDCJ Holdover; bed
  request = HOL-CMC Holdover; routine discharge (Rx, instructions, follow-up, print AVS).
- **Discharged, return to HG infirmary:** Dispo = Transfer – TDCJ Infirmary; bed
  request = CMC-CMC Infirmary; routine discharge.

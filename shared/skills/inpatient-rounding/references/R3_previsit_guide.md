# R3. PRE-VISIT GUIDE (01_previsit)

Command: "p1", "phase 1", "guide", "previsit". A named single section = print only that section with its header.
Order: SUMMARY -> INTERVAL EVENTS -> CHECK IN CHART -> PROBLEMS TO DISCUSS -> PATIENT UPDATE -> QUESTIONS -> EXAM. Start the guide at SUMMARY.
Each header prints bold on its own line: **CHECK IN CHART**. Always print every section in full; never stop early. An empty section prints its header and its "none" line.
Private prep sheet, never note text. Brief: the whole guide fits one screen. Values allowed anywhere they save a chart click.
Never copy instruction text, labels, or example placeholders from this section into the output; print only case-specific content. Requested one-line answer blanks and labeled expected simulated exam templates follow [simulation testing](simulation-testing.md), rather than the default question/check format below.
SCOPE: the guide is the daily delta against the most recent progress note or H&P. Every actionable item needs evidence in the 24h before the anchor. Older facts are dated comparators or admission context. Put the most pressing decision first. Group exam targets by organ system.
HARD RULE (SKILL.md): patient care only. Connect the dots, catch what is brewing (R2 BREWING CHECKS), and flag what did not happen. Admin and chart housekeeping never appear here; they go to `audit` only.

Chart review before drafting (silent)
- Match the supplied material to this encounter. Set aside worked examples. Exclude a suspected wrong-patient chunk and clarify the mismatch before using it. Use the records already supplied, in any order.
- Walk the prior note by problem. Match each intended action or follow-up to current orders, MAR, results, and consultant, nursing or therapy observations. Track what was recommended, ordered, actually done, held, pending or still unverified. A collected specimen without component results is pending. An incomplete order list cannot establish a missed order.
- Then look beyond yesterday's list. Does a new result, nursing escalation or consultant finding point to a separate problem? Put it in the existing section where it changes care. Surface each discrepancy once. Give source, event time and dated comparator when they change interpretation. Use the current order for prescribed care, the MAR for administration and the result for the finding. A later signature alone cannot settle conflicting evidence or establish that a code-status discussion took place.
- Screen for urgent changes using R2 and local critical values when supplied. For antibiotics, review indication, course day, cultures, narrowing, IV-to-PO eligibility and stop date. Check VTE prophylaxis against therapeutic anticoagulation and bleeding risk. Reassess glucose, BP and renal/hepatic dosing in clinical context. Check whether the reason for a home-med hold, inpatient-only drug, line or telemetry still applies. Escalating PRN opioid or sedative use may change what to assess at bedside.
- With new confusion, look for a change in medication exposure, sleep, sensory aids, mobility, bowel or bladder function. Consider withdrawal, nutrition and other contributors when the chart supports them. A brief validated delirium assessment belongs in EXAM when it would clarify today's change.
- Separate medical readiness from the feasibility of the proposed destination. Name the remaining milestone and the step that could clear it today (stairs, equipment, caregiver, medication access or teaching). Give a discharge date only when supported.

SUMMARY
Brief one-liner: who, why admitted, current trajectory and main decision or discharge barrier. Use a verified hospital day, support level or goals-of-care limitation when it helps orient rounds. Give an active safety concern prominence.

INTERVAL EVENTS
Same section in p1 and the note. Very selective, clinically consequential events, then compact treatment/PRN tracking. Read notes first, then reconcile orders, MAR and decisive results. Do not build the section from medication administrations alone.

Opening and events:
- First event line: "No events overnight; [brief nursing observation, e.g., ambulated to commode]" only when the notes support a quiet night and that observation. If an acute event occurred, lead with it. Missing nursing documentation never proves an uneventful night or normal function.
- Prefer "overnight", "yesterday" or "this morning" when precise timing does not change interpretation. Midnight to 6AM can be "overnight". Preserve exact timing only when clinically necessary, such as a time-sensitive dose or sequence; retain precise source timestamps in the evidence/checkpoint, not every event bullet.
- One short line: event/decisive value -> intervention -> response or pending reassessment. Fictional format: "Overnight Hgb 6 -> 2 units PRBC -> repeat CBC pending." Never turn an ordered intervention into one actually given.
- Include only events new since the last note that change care or readiness for discharge and would matter on rounds. Usually no more than 5; an unstable night may justify more. Omit routine labs, routine administrations, unchanged abnormalities and resolved minor vital excursions without intervention. Include a decisive value when it explains the event; do not add a lab inventory.
- Integrate consultant input qualitatively into the event list, e.g., "ID provided antibiotic recommendations." No Consults heading, service roster, dose/duration details, test lists or "no new recs" entries. Recommendation details and adoption status belong in the owning A/P problem; implementation gaps go in CHECK IN CHART/PROBLEMS TO DISCUSS.
- Clinically important device/access events belong here near the other management changes: catheter problems relevant to the admission, removal/exchange affecting source control, or failed access delaying treatment. Omit routine PIV placement. No separate Devices tracking line.
- Relevant isolation/precautions may follow the opening event line. State their status only when established; absence of documentation is not "none".
- Removing the MAR and Given despite hold display blocks does not remove medication review. A clinically important missed/held dose or administration despite a hold may qualify as a brief event; otherwise keep it in the appropriate verification/audit section.

Treatment and PRN tracking, after events:
- No standalone MAR, Given despite hold, Insulin or Devices labels.
- Abx: one line per active infection: "[drug dose route frequency], day N, started [date] for [reason]; planned end [date/duration]." Day count uses verified administrations. If day 1, say "started [date]" rather than a redundant day count. Do not force day N/Y when total duration is not established. Intended end-of-course/trial date comes from clinical notes or the resident's explicit plan, not an auto-expiring order. Omit an unsupported planned end and flag a consequential discrepancy outside the note. Actual stopped/completed treatment may be established by the owning order/MAR source and is distinct from an intended course length.
- Specialty/time-limited medications use the same compact drug/dose/route/frequency, start/date, indication and note-supported planned end format; chronic therapy need not have a fabricated end date. No medication inventory or extra consultant details.
- Glucose and insulin move to OTHER NEW LAB RESULTS under Glucose per R5: range, time of the low/high, current basal/prandial regimen and actual correctional units given. Do not duplicate an Insulin line here. A genuine hypo/hyperglycemic event can still qualify above.
- PRNs: pain first, actual drug/dose/route x administration count, then total verified opioid MME for the covered window; nausea drugs with dose/route x count; then other relevant PRNs in the same format. Example structure: "Pain: [drug dose route xN]; total MME [N]; Nausea: [drug dose route xN]; Other PRNs: [drug dose route xN]." No prior-day MME comparison, prescribed-frequency inventory or unused-PRN catalog. Omit empty groups unless verified absence is useful. Buprenorphine stays separate from MME. Incomplete MAR coverage must not appear as a complete total; preserve the coverage limitation outside the note or label a reported subtotal.

EXAMPLE - INTERVAL EVENTS (fictional formatting only, not treatment guidance)
**INTERVAL EVENTS**
\- Overnight Hgb 6 -> 2 units PRBC -> repeat CBC pending
\- ID provided antibiotic recommendations
\- Difficult IV access delayed treatment
Abx: [drug dose route frequency], day 4, started [date] for [infection]; planned end [date from clinical note]

CHECK IN CHART
What to verify before I see the pt. Format: "\- [what to check]: [what the data show] ([why it matters])". Max 6 unless more would change today's plan. Most urgent first, priority triggers (R2) on top w/o urgency words.
- Fixed first lines, exempt from the cap, in this order:
  - Active order vs allergy or contraindication: "\- CONFLICT: [order] vs [allergy/contraindication] ([why it matters])".
  - Flag a care-relevant consultant recommendation as "not yet ordered" only when the supplied active orders support that conclusion. If the orders are incomplete, identify what is needed to verify the gap.
  - A consult planned but never ordered is a gap. A consult already ordered without a note is "ordered, recommendations pending".
- Important med held, missed, or refused w/o a known reason (anticoag, abx, insulin, AEDs, cardiac, steroids, immunosuppressants): "\- Ask RN why [drug dose] held x[n] [time] ([why it matters])". Never "reason not on MAR".
- Med gaps: unexplained home-med omission, repeated PRN use, missing high-alert monitoring (R2), missing abx duration, missing device removal plan.
- A med w/ no owning problem: "\- Keep or d/c [drug dose route freq] ([started MM/DD by service])". Never "no indication".
- Ordered and overdue: a test, procedure, or therapy past its due time and not done ("\- MBS: ordered 10/19 2PM, not done, pt strict NPO (call SLP/radiology to schedule)"). Future tests are not overdue. A pending result is never an item; I get notifications.
- Contradictions: both values w/ times, never pick a side ("\- K: 3.2 BMP 6AM vs 4.1 VBG 7AM (repletion decision)").
- Brewing: each R2 BREWING CHECK that fires, w/ its values.
- Working dx that the data no longer fit: name the dx-defining test or disease-specific tx that is missing ("\- Calciphylaxis vs soft tissue infection: no biopsy, no sodium thiosulfate (abx alone won't heal calciphylaxis)").
- Incomplete record: name the specific record to check.
- No orders pasted: one bullet saying so.
- Nothing found: "\- nothing flagged".

PROBLEMS TO DISCUSS
One short line per decision for the attending, highest priority first. Lead with what is wrong and the deciding finding, then the specific option and why it fits. For a treatment alternative, give the patient-specific reason to favor it. For a proposed medication, include agent, dose, route, frequency and duration or stop/restart criterion when supported. Apply R2 dose checks. If eligibility or a dosing input is missing, keep the proposal conditional and identify the check. Observation can be appropriate with a reason. Put urgent chart-based triggers with the corresponding CHECK IN CHART item and bedside warning signs with the relevant EXAM target.

PATIENT UPDATE
What I tell the pt when I walk in, before the questions. One short line per active problem, plain spoken English in 2nd person, ready to say aloud: what the result or change means, what happens today, what we are waiting on. Include what a consultant said and a tx the pt declined w/ the risk discussed. E.g. "\- Your bowels are moving better, so the medicine is working." No jargon, unconfirmed diagnoses, prognosis, discharge promises, or results I have not reviewed.

Selecting bedside priorities (silent; applies to QUESTIONS, EXAM and top 3)
- Start with the decision still open today: wean support, restart or stop a drug, act on a consult recommendation, or test discharge readiness. Choose the question or finding that would distinguish the options. Also look for bedside-detectable harm from a current drug, device or recent procedure when today's data show ongoing exposure or concern.
- Prefer information only the bedside can supply. Skip facts already measured and answers already obtained today unless the condition changed or accounts conflict. When time is short, keep immediate safety and management decisions first. On a requested mid-day refresh, give only new or changed targets unless asked for the whole list.
- For an unfamiliar maneuver or drug-specific check that would change care, verify its purpose and limits using an appropriate current source. Use generic clinical search terms. Do not present an unverified maneuver as decisive.

If note-ready assessment edits are explicitly requested, use compact unlabeled clinical reasoning prose with only the course details needed to explain today's plan. Dates only when important; no goal or endpoint line.

QUESTIONS
Choose patient questions and exam findings that could elicit a pertinent positive or negative distinguishing the working diagnosis from a live alternative.
Max 6, ordered by problem (most problematic first), only about the current clinical trajectory: is the active problem better or worse, is today's tx working or causing harm, and what the attending is likely to ask me. Include a question only if its answer could change today's plan, confirm progress, or catch a red flag. Re-ask even if documented yesterday when the answer could have changed. Never moot or impossible questions for this pt.
One main question per line. Nest only useful answer-dependent patient questions beneath it. Drop filler words while preserving what each question asks, including management-changing details about onset, location, severity, recurrence and treatment response. Keep previously requested questions when revising. Omit an empty "no" branch. Put clinician maneuvers in EXAM and chart checks in CHECK IN CHART.
Ask about a previous symptom when today's evidence or the resident's explicit request makes its course relevant. Phrase it as a question about recurrence or resolution. Use the words you would say to the patient. When possible, open with a functional comparison ("How far can you walk today before you have to stop?"). Ask about actual home or OTC med use, the home setup, or teach-back of a changed regimen only when it could change today's care or safe discharge. Avoid generic ROS.

EXAM
Organ-system headings, one concrete finding/check per nested bullet. Use the relevant systems only; prioritize checks that change care today. Brief note-style prompts, not running lists or broad labels. Examples: General/Neuro -> "A&O x4?"; CV/perfusion -> "Cap refill brisk?", "Extremities warm?"; HEENT -> "Trismus?", "EOM intact?", "Pain w/ EOM?". Specify what to assess instead of "alertness", "perfusion", "mouth opening", or "eye movements/vision". Preserve clinical meaning when cutting words. Use side, site or distribution when relevant. A dated prior finding or the decision a positive finding would change belongs beside the check only when it helps interpret the exam. These are targets to assess, never assertions of normal findings. Patient symptom questions and their follow-up branches stay in QUESTIONS. Bladder scan belongs in CHECK IN CHART or an order discussion. This section permits nested Markdown bullets despite R1's flat-bullet rule.

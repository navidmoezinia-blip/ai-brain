# Orders / gaps / field selections

- `What to order`: recommended stabilization, tests answering leading/dangerous questions, triggered tests with triggers, and reassessment/disposition needs. Include indicated groups only, each item with a short reason; no automatic panels. Distinguish recommendations from placed orders; cite guidance outside.
- Placed orders + `what else`/`gaps`: only missing/questionable items and why. Account for canceled, pending, duplicate, and completed items; do not restate the placed list. Identify missing information gating uncertain advice.
- Explain a test that is not routinely indicated when it changes the requested decision.
- Epic field-picker screenshot: just supported picks; identify an indeterminate consequential selection instead of guessing.

# MDM / disposition-only / section redo

`MDM` means only MDM. `Dispo note`, `why appropriate for discharge`, and `discharge rationale` mean only the requested disposition reasoning. `Updated ED course`, `replace the plan`, or a named section means only that section. Integrate relevant supplied facts and corrections without regenerating earlier stages.

For an initial or fully rewritten MDM, including within a full note, use this order:

1. **One-liner:** age/sex, presenting problem, and only the background that changes today's reasoning.
2. **DDX:** leading diagnosis and dangerous alternatives, with short `For` / `Against` bullets using supplied findings. Keep uncertainty when a diagnosis remains unresolved. Omit an unsupported side; absence of data is not evidence against a diagnosis. Do not repeat the HPI or exam or put orders/actions beneath diagnoses.
3. **PLAN:** a separate section for tests, treatment, and reassessment. Use `- X ordered - [what it checks / reason in a few words]`, with maximum telegraphy. Example, only when the order is supplied: `- Troponin ordered - myocardial injury`. Use actual status (`planned`, `ordered`, `given`, `pending`, etc.); this format never establishes that an order was placed. Treatment/reassessment lines follow the same action-status/reason pattern when applicable. Keep routine orders terse; no expanded pathophysiology explanations. Include supplied responses or consultant recommendations briefly. Additional recommendations stay outside the note.
4. **DISPO:** intended or completed disposition with supporting reasoning and supplied follow-up. Preserve the difference between the discharge decision and demonstrated readiness.

Write the one-liner as the first bullet, followed by `DDX`, `PLAN`, and `DISPO` headings with short telegraphic bullets. One clinical point per bullet; no prose paragraphs or HPI recapitulation. A full note includes MDM inside the note's single block. An MDM-only request gets one fenced `text` block containing only MDM. Narrow section requests and automatic addenda retain their own formats.

Link disposition to today's evaluation/reassessment. A discharge decision differs from evidence of readiness. If evidence is insufficient, document supported facts neutrally and identify the specific consequential gap outside. Drafting instructions does not mean they were discussed.

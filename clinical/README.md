# `clinical/` — Residency & Clinical Care

Nested by clinical setting/rotation so all prompts, quick-reference guides, Epic workflows, non-PHI contacts, and tools for a setting stay together:

- **[`inpatient/`](./inpatient/)** — Ward admission/progress/discharge note prompts, rounding presentations, institutional house style
- **[`clinic/`](./clinic/)** — Outpatient workflows, preventive screening & guideline vigilance, quick-ask guides
- **[`rotations/`](./rotations/)** — Rotation-specific hubs (e.g., [`ed-aer1/`](./rotations/ed-aer1/); add new subfolders like `ob/`, `peds/`, `icu/` as rotations start)
- **[`study/`](./study/)** — ITE/Board study notes, Anki decks & deck-builder scripts, clinical pearls

> **Strict Rule:** Zero PHI. De-identify all examples and templates completely.

Pre-visit guides (p1) must be readable at a glance. Navid's rules (11/01/2026, now written into the inpatient-rounding skill R1/R3/R4):
- INTERVAL EVENTS: only discrete events that change today's management; no routine labs, stable vitals or I/O. A new lab goes in only when it evaluates a new concerning finding, and then as "finding + test", without results.
- QUESTIONS: max 6, only about the current clinical trajectory.
- Med names: chart-facing brands (Symbicort, Bumex, Eliquis, Coreg, Norco, Hyper-Sal), each followed by its goal in parentheses; no long generic combo names.
- A/P italic paragraph: a clinical argument, not a chronology; "less likely/not established", never "ruled out".

**Why:** he got a too-long guide on 11/01/2026 and said "way too much info, I can't read all that."

**How to apply:** default to fewer, shorter bullets in every rounding output. See [[feedback-previsit-24h-only]] and [[feedback-previsit-patient-care-only]].

# `clinical/inpatient/`

Keep all Family Medicine inpatient materials together here:
- H&P, progress note, and discharge summary prompt templates
- Rounding oral presentation templates & discrepancy checklists
- Institutional inpatient house styles and workflows (zero PHI)

## Files
- `global-ruleset.md`: rules that run first in every inpatient note chat (Doximity, QH, OpenEvidence)
- `ed-consult-reference.md`: ED-to-FM phone consult checklist and top 15 admit complaints
- Skills: `shared/skills/inpatient-rounding`, `inpatient-chart-check`, `epic-chart-collect-to-notes`, `openevidence-chart-check-upload`, `openevidence-upload-patient-docs`

- "Use UpToDate" = UpToDate **Expert AI** (ask it questions), not manual topic search. Reach it via the UTMB library proxy https://ai-uptodate-com.libux.utmb.edu/ (UTMB login + Duo; if the login page shows, stop and tell Navid) or https://ai.uptodate.com/?dpRedirect=false when signed in.
- Navid wants several Expert AI tabs open in parallel, one question each.
- OpenEvidence flags automation in his real Chrome ("Access is temporarily restricted", 11/01/2026) after one submitted question. Treat it as a tool that gets blocked.
- uptodate.com search without sign-in gives only snippets.

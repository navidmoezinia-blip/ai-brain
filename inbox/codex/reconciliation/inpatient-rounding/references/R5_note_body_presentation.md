# R5. NOTE BODY AND PRESENTATION (03_note)

CURRENT EPIC SMARTPHRASE OUTPUT
Commands: "note", "full note", "whole note", "p2". Generate only the requested manual sections in this order:
REASON FOR ADMISSION/PRIMARY DIAGNOSIS -> relevant PMH -> INTERVAL EVENTS -> TODAY -> PHYSICAL EXAM -> OTHER NEW LAB RESULTS -> MICRO -> OTHER NEW STUDIES -> active A/P problems -> CHRONIC STABLE CONDITIONS -> RESOLVED -> DVT PROPHYLAXIS -> PT/OT -> BARRIERS TO DISCHARGE -> APPENDIX: ONE-TIME WORKUP / PRIOR STUDIES (when applicable) -> IMMEDIATE ITEMS TO FOLLOW-UP -> HOSPITAL COURSE -> OUTPATIENT FOLLOW-UP.
SUGGESTIONS (not for the note) stays separate at the very end. R4 governs the A/P and bottom sections, including the resident-only immediate-items field.

Epic fills identity, code status, service/admission dates, length of stay, VITALS, I/O, recent CBC/BMP and associated electrolytes, and RADRESULTS30DAYS. Use those data for reasoning without repeating their tables. Do not generate an attestation or signature. Missing manual content stays blank. This layout replaces the old full-objective-table layout; output an alternate template only when requested.

PRELIMINARY WORKSHEET / SIMULATED TEST
For a requested preliminary note, preserve this section order and use patient-specific, one-line fill-in questions in TODAY. For simulated, deidentified pre-EMR-integration testing, [simulation testing](simulation-testing.md) permits a clearly labeled, unconfirmed expected exam template with observed/changes blanks. This is a worksheet variant, not a performed exam. Replace only findings the learner actually confirms or corrects; do not use expectations as A/P evidence. The current-bedside-only TODAY and PHYSICAL EXAM rules below govern the actual clinical note.

REASON FOR ADMISSION/PRIMARY DIAGNOSIS
One short sentence only: "Admitted for [most specific supported dx or presenting syndrome] after presenting with [key symptoms/precipitant]." (If presenting symptoms are absent from partial records, write "Admitted for [admission reason]." without placeholder text.) No ED vitals, lab values, imaging, interventions, response chronology or separate ED COURSE section. Use the presenting problem if the diagnosis is unconfirmed; add no unsupported details. Relevant PMH is a separate compact line: up to 5 conditions by admission relevance, psychiatric diagnoses included, with useful severity/device/baseline anchors (e.g., EF, baseline Cr, home O2) and no doses. Write "Relevant PMH: none" only when verified negative; omit the Relevant PMH line if PMH was not captured rather than writing "not supplied". Routine unrelated history stays out.

INTERVAL EVENTS
Use R3's current section: supported overnight opening plus brief nursing observation (or "No acute events overnight" alone when nursing detail is absent; omit the overnight claim altogether if overnight notes were not supplied), or acute event -> response/pending reassessment; qualitative consultant input; relevant device events; compact antibiotic/specialty-course and actual PRN tracking. No dedicated Consults, MAR, Given despite hold, Insulin or Devices blocks. Reconcile through the actual chart anchor; no routine lab inventory.

TODAY
Use the resident's bedside answers and dictation only, written as one concise telegraphic prose paragraph (fragments joined by commas/semicolons; no "patient reports/states"). Match numbered answers to the actual questions; free dictation by meaning. Separate symptoms, exam and management decisions. Include dictated functional trajectory, targeted pertinent negatives that rule down live differentials, and daily cares when dictated; omit unasked boilerplate ROS. When bedside history is limited or unobtainable, state the clinical barrier and collateral/interpreter source ("Hx limited by acute encephalopathy; collateral per daughter"; "Spanish interpreter #..."). Quote only supplied words. "Rest negative" applies only to questions the resident says were asked. Before dictation (outside preliminary worksheet mode), print **TODAY** with nothing beneath it; never write "not supplied" or "not provided."
- Compare like with like before flagging discrepancies. Different observers or dates may reflect genuine change. Never silently correct a possible drug, dose, value, negation or laterality error. If the same finding conflicts and the distinction matters, preserve attribution and flag the exact discrepancy outside the paste-ready note.

PHYSICAL EXAM
Only from the resident's current bedside findings. One line per system, abnormal findings first, concrete clinical shorthand ("NAD," "RRR," "soft, NT, ND"; never "WNL," "unremarkable," "not supplied," or "not provided"). Always General, Lungs, CV, Abd, then other relevant dictated systems in anatomic order; silently omit unexamined non-core systems. Preserve side/site, O2 delivery when dictated, grades, and meaningful comparison. Before exam dictation (or when a core system was not dictated), print the core label (General:, Lungs:, CV:, Abd:) with nothing after the colon. Write "deferred ([clinical barrier, e.g., splint / acute distress / pt declined])" ONLY when the resident explicitly states that exam component was deferred or blocked. "Rest of exam normal" cannot establish a specific maneuver or negative not described. An untestable maneuver is not intact. Prior chart exams may appear in a separate dated reference, never as today's performed exam. The previsit EXAM remains specific to the patient and the decision at hand per R3.

OTHER NEW LAB RESULTS
Newly resulted, clinically relevant values within the last 24h that Epic does not already autofill. One short text line per test: test + single new result, without prior/admission values or comparison columns. Keep necessary units. Trends may still inform the A/P when clinically important. Relevant pending tests are identified as pending with the question being evaluated; do not imply a new result. If none apply in the last 24h, print the bold header with nothing beneath it. Routine labs do not move into Interval Events.
Glucose (print ONLY when insulin is ordered/given or glucose is abnormal/actively tracked; otherwise omit the Glucose line completely): "Glucose: [24h range]; low [time], high [time]. Basal: [drug dose frequency or none]. Prandial: [drug dose frequency or none scheduled]. Correctional: [actual units given/24h]." Use the actual timestamps of the extrema, including minutes if needed; this is an exception to generalized event timing. Distinguish prescribed basal/prandial insulin from actual correctional use and avoid counting scheduled mealtime insulin as sliding scale. If a sub-component's source is incomplete, omit that sub-label rather than inventing values or writing "not supplied."

MICRO
Cumulative relevant microbiology for this admission, in text rather than a table. One line per specimen: specimen/collection date when needed to distinguish samples, organism or result, relevant susceptibilities, and explicit awaiting collection/pending/preliminary/final status. Keep "no growth to date" distinct from final negative. Do not invent susceptibility or clearance. An older final result remains dated reference; its continued inclusion alone does not establish a new event or current treatment decision. Pathology can be included here when relevant, retaining specimen and status. If no micro/pathology specimens exist this admission, leave blank beneath the header.

OTHER NEW STUDIES
This replaces the ambiguous Others label. Traditional radiology is already autofilled (though if the resident dictates their own independent review of imaging, preserve that personal read concisely in the owning A/P problem). Include relevant non-radiology diagnostics only if newly performed/resulted/updated within the last 24h, such as echo, ECG, EEG or endoscopy, with a brief finding, status, and resident personal review when dictated ("ECG personally reviewed: sinus, QTc 448 ms"). Relevant pending studies stay identified as pending. If none in the last 24h, print the bold header with nothing beneath it. Older studies belong in the cumulative reference appendix; do not repeat a cumulative study table here.

PRESENTATION ("pres", "present", "verbal")
What I say out loud on rounds, delivered live, not read from the note: about one minute (120-160 words) unless a variant below says otherwise. Short spoken sentences, no headers, tables, bullets, or file references. Every claim rests on data from the last 24h; an older value appears only as a comparator ("creatinine down to 1.6 from 2.1"). Built only from facts in the chat; suggestions are the same ones as in SUGGESTIONS.
The skeleton is the same in every version. The phrasing below is a pattern, not a script: build each presentation from the whole context.
1\. Synthesis of the bedside and objective data, together:
\- Bedside: what the pt told me that matters to the active problems.
\- Exam: the findings we're following, say "nothing else abnormal" only if my bedside account supports that scope.
\- Vitals as rounded spoken ranges ("BPs 110s over 60s, heart rate 70s to 80s"), never raw min-max.
\- Labs, micro, imaging: what is important, new, or needs follow-up, each w/ its direction ("white count down to 11 from 17"). Use "labs otherwise stable" only when comparable results support it.
2\. Problems, only those keeping the pt in the hospital, most important first: "For this [age]-year-old admitted for [dx], the biggest problem right now is [problem]. We're doing [tx]." Working: "we'll keep doing it." Not working: my suggestion w/ its reasoning. Heavy reasoning only when I am proposing something new. Then "Next, ..." for each remaining problem.
3\. Barriers to discharge, last, one sentence.
4\. A value in my note that conflicts w/ the raw data: say the raw value in place, then "Check: [item]" at the very end.
Variants (same skeleton):
\- "pres new attending": add a one-line course after step 1 (why admitted, ED workup, consults involved, course-defining results and cultures); up to 2 minutes.
\- "pres discharge": Ready for discharge (the evidence); Med changes vs home w/ dose, reason, end dates; Follow-up w/ every pending result and its owner; Still needed.
\- "pres ultra": about 30 seconds: one-line status per problem plus suggestions.
Over the word budget: compress the synthesis first, then merge minor problems into one clause.
